# Python Data Types Explorer 🐍

This is my very first Python program! I created this project to practice identifying and working with different data types in Python.

## 🚀 What this program does
The script initializes several variables and uses built-in Python functions to verify their types. It covers:
* **Strings**: Storing text data.
* **Booleans**: Handling True/False logic.
* **Integers**: Working with whole numbers.
* **Floats**: Working with decimal numbers and using `isinstance()` for validation.
